# 📊 Statistical Business Analysis

## 👨‍💻 Project Overview

This project focuses on analyzing business sales data using statistical techniques and Python libraries. The objective is to understand sales patterns, explore relationships between numerical variables, perform hypothesis testing, and generate useful business insights.

This project was completed as part of my Data Science learning journey.

## 🎯 Project Objectives

* Calculate descriptive statistics.
* Analyze data distributions and normality.
* Explore correlations between numerical variables.
* Perform hypothesis testing.
* Calculate 95% confidence intervals.
* Build a linear regression model.
* Generate business insights and recommendations.

## 🛠️ Tools and Technologies

* **Python** — Statistical analysis and programming
* **Pandas** — Data manipulation and analysis
* **NumPy** — Numerical calculations
* **Matplotlib** — Data visualization
* **Seaborn** — Statistical visualizations
* **SciPy** — Statistical tests
* **Scikit-learn** — Linear regression and model evaluation
* **Google Colab** — Development environment
* **GitHub** — Project documentation and version control

## 📈 Analysis Performed

### 1. Descriptive Statistics

Calculated statistical measures such as:

* Mean
* Median
* Mode
* Standard deviation
* Minimum and maximum values

### 2. Distribution Analysis

Explored numerical data distributions using histograms and statistical methods.

### 3. Correlation Analysis

Examined relationships between numerical variables using correlation analysis and visualizations.

### 4. Hypothesis Testing

Performed statistical hypothesis tests to investigate patterns and differences in the data.

### 5. Confidence Interval

Calculated a 95% confidence interval to estimate the population mean.

### 6. Linear Regression

Built a linear regression model and evaluated its performance using the R² score.

### 7. Business Insights

Reviewed the statistical results and identified potential areas for further business analysis and improvement.

## ▶️ How to Run

1. Download or clone this repository.
2. Open Google Colab.
3. Upload `statistical_analysis.ipynb`.
4. Upload `business_data.csv` when required by the notebook.
5. Install any missing libraries using the commands provided in the notebook.
6. Run the notebook cells in order.
7. Review the statistical results, visualizations, and business insights.
